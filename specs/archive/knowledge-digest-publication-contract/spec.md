# 功能规格：知识发布合同与离线可读输出

> 来源：已接受的“知识发布合同”决策。本文只定义用户可观察行为、边界和验收。

- **功能名**：知识发布合同与离线可读输出
- **来源**：已接受决策 D-01 至 D-06
- **状态**：草稿

## 速读卡（30 秒）

- **一句话需求**：知识库使用者每天处理新资料时，能从根目录直接读到按分类组织、标题可读、可安全增量更新的知识页。
- **核心改动点**：
  - 新知识库直接生成读者入口和分类导航。
  - 旧知识库只更新已声明、已托管的文件。
  - 稳定主题身份与可读标题、文件名分离。
- **最大影响面**：每日知识同步的输出目录、旧知识库保护和读者导航。
- **验收信号**：读者不进入审计目录；手写旧页不被改动；离线运行不调用模型或 embedding。

## 1. 问题与紧迫性

当前正式知识页以主题哈希命名并集中放在同一目录，读者只能从审计来源索引进入。知识本身可追溯，但无法作为每天可直接阅读和维护的个人或企业知识库。旧库又缺少明确的托管边界，直接改写有覆盖手写内容的风险。

本期必须先补齐发布合同：让新库可直接发布，让旧库可安全增量更新，同时不降低已有内容、溯源和写入安全合同。

## 2. 背景、目标与范围

### 背景

知识消化已能生成带 Summary、Evidence、Provenance 的主题内容和审计记录。原始设计要求知识库结构约定决定目录和字段，但未定义读者首页、分类导航、可读路径及旧库托管边界。

### 目标

- 新空知识库首次离线运行后成为可直接浏览的知识库。
- 已声明的旧知识库能每日新增或更新系统托管内容，手写内容保持不变。
- 读者从首页进入分类页再进入主题页，不依赖内部审计目录。

### 范围内

- 发布结构声明、首次新库初始化、读者首页和分类索引。
- 托管主题页的稳定身份、离线可读标题、可读路径和路径锁定。
- 旧库托管范围验证、只新增和更新、无删除分页收缩规则。
- 不调用 LLM 或 embedding 的端到端验收。

## 3. 用户场景与状态覆盖

### SCN-001：首次发布新知识库

- **角色**：知识库维护者
- **Given**：目标目录不存在或为空，且维护者运行一次离线知识消化。
- **When**：系统初始化并发布有效输入资料。
- **Then**：根目录出现托管首页、分类索引和可读主题页；读者可从首页访问全部已发布主题。

### SCN-002：更新已托管旧知识库

- **角色**：每日同步的知识库维护者
- **Given**：旧库有有效发布结构和系统托管主题页，也有手写页面。
- **When**：系统处理当天新增或更新资料。
- **Then**：只在声明范围内新增或更新托管文件，手写页面和未托管页面字节不变。

### SCN-003：拒绝不安全旧知识库

- **角色**：知识库维护者
- **Given**：旧库非空但缺少有效发布结构，或拟更新页面缺少托管身份。
- **When**：系统尝试发布。
- **Then**：在正式写入前明确失败，首页、索引和主题页均不改变。

### SCN-004：离线可读命名与稳定链接

- **角色**：知识库读者
- **Given**：一个主题首次发布，或已有托管主题再次更新。
- **When**：系统确定显示标题和路径。
- **Then**：首次按“已有托管标题、来源 title 或 H1、文件名”的顺序命名；已发布路径保持不变，即使显示标题后来变化。

### SCN-005：分页收缩但不删除旧文件

- **角色**：知识库读者
- **Given**：一个已托管主题此前有多个分页，后续更新后分页数量减少。
- **When**：系统发布新布局。
- **Then**：现行导航只指向当前分页；不再现行的旧分页保持原字节不变且不删除，不作为当前导航目标。

### SCN-008：旧知识库空输入

- **角色**：每日同步的知识库维护者
- **Given**：旧库已有有效发布结构、托管主题页和读者导航。
- **When**：本次输入没有可发布资料。
- **Then**：系统成功结束但不创建、更新、删除或从导航移除任何正式文件。

### SCN-006：离线安全运行

- **角色**：自动化维护者
- **Given**：运行指定为离线模式。
- **When**：系统生成或更新知识库。
- **Then**：不发出 LLM 或 embedding 请求，仍生成可读导航和完整主题页。

### SCN-007：无法离线分类的主题

- **角色**：知识库维护者
- **Given**：主题不匹配发布结构中的明确分类规则。
- **When**：系统首次发布该主题。
- **Then**：主题进入发布结构声明的“待归类”分类；系统不伪造语义分类。

### 状态覆盖清单

- [x] **默认态**：SCN-002
- [x] **空态**：SCN-001；新空库只生成首页和分类索引，不生成空主题页。SCN-008；旧库空输入不改变任何正式文件。
- [x] **错误态**：SCN-003
- [x] **加载态**：N/A — 本地命令在完成后输出结果，不提供后台读者界面。
- [x] **取消态**：N/A — 本期不改变既有中断和恢复合同。
- [x] **边界态**：SCN-005、SCN-007
- [x] **权限态**：SCN-003；托管标记和声明范围是写入权限边界。
- [x] **竞态**：N/A — 本期沿用单写者合同，不新增并发发布能力。

## 4. 产品事实与假设（PFACT）

- **PFACT-PUBLISH**：新库直接发布、旧库只新增和更新，且不删除旧页面。
  - **status**：`verified`
  - **证据或来源**：已接受决策 D-01、D-03。
  - **关联**：FR-PUB-001、FR-PUB-002、FR-PUB-005；AC-01、AC-02、AC-05。

- **PFACT-EMPTY**：新空库可初始化读者结构；已有旧库的空输入不改变任何正式文件或导航。
  - **status**：`inferred`
  - **证据或来源**：从 D-01 的新旧库分界和 D-03 的无删除限制唯一推导；限制是空输入不提供重新编目授权。
  - **关联**：FR-PUB-001、FR-PUB-007；AC-01、AC-08。

- **PFACT-SCOPE**：只有发布结构声明目录中的系统托管文件可被日常更新；手写或未托管页面不自动接管。
  - **status**：`verified`
  - **证据或来源**：已接受决策 D-02。
  - **关联**：FR-PUB-002、FR-PUB-004；AC-02、AC-03、AC-04。

- **PFACT-IDENTITY**：主题稳定身份用于更新，可读标题和首次路径用于阅读；标题变化不自动改变路径。
  - **status**：`verified`
  - **证据或来源**：已接受决策 D-02、D-04。
  - **关联**：FR-PUB-003；AC-03。

- **PFACT-OFFLINE**：本期离线运行不使用 LLM、embedding 或外部网络；默认 LLM 命名属于后续任务。
  - **status**：`verified`
  - **证据或来源**：已接受决策 D-05。
  - **关联**：FR-PUB-006；AC-06。

- **PFACT-QUALITY**：可读发布不能移除主题页的 Summary、Evidence、Provenance、来源索引、归档、原子写和 300 行上限。
  - **status**：`verified`
  - **证据或来源**：已接受决策 D-06 和既有质量合同。
  - **关联**：FR-PUB-004、FR-PUB-005；AC-04、AC-05、AC-07。

- **PFACT-CATEGORY**：离线阶段只能遵循已声明分类，无法判断时使用“待归类”，不承诺语义化自动编目。
  - **status**：`inferred`
  - **证据或来源**：从 D-04 的离线标题限制和 D-05 的 LLM 延后唯一推导；限制是标题与分类质量受输入元数据影响。
  - **关联**：FR-PUB-001、FR-PUB-004；AC-01、AC-04。

## 5. 功能需求

### 发布结构与初始化（PUB）

发布结构是知识库的唯一读者导航和托管范围声明。新库可生成默认发布结构；非空旧库必须已有有效声明，系统不得猜测用户目录含义。

- **FR-PUB-001**：系统必须让不存在或为空的新知识库直接初始化为可读发布结构。
  - **范围边界**：初始化唯一的 `kb.structure.md` 发布声明、根首页、分类索引和默认“待归类”分类；非空旧库不自动补写或猜测结构。
  - **声明合同**：默认声明使用 `publication_home: Home.md`、`publication_index_root: indexes`，并在 `publication_categories` 中声明 `id: pending`、`title: 待归类`、`topic_dir: pages/待归类`。自定义声明可增加分类，但必须保留唯一的 `pending` 分类；首页、索引和主题目录均为相对安全路径，且不得互相重叠。
  - **依据**：D-01、PFACT-PUBLISH、PFACT-CATEGORY、PFACT-EMPTY。
  - **场景**：SCN-001、SCN-007。
  - **验收**：AC-01。

- **FR-PUB-002**：系统必须只在有效发布结构声明的范围内新增或更新托管文件。
  - **范围边界**：主题页必须同时声明 `managed_by: KnowledgeDigest`、`digest_kind: topic`、`digest_topic_id` 和 `digest_published_path`；首页和分类索引必须声明 `managed_by: KnowledgeDigest` 及 `digest_kind: home` 或 `digest_kind: category`，但不使用 `digest_topic_id`。未托管、未声明、不安全或路径冲突的既有文件必须拒绝。
  - **旧库导航规则**：声明位置为空时可创建带上述导航标记的首页或分类索引；声明位置已有未托管文件时必须失败，不能覆盖。主题页的更新必须同时匹配稳定主题身份与锁定路径。
  - **依据**：D-01、D-02、PFACT-PUBLISH、PFACT-SCOPE。
  - **场景**：SCN-002、SCN-003。
  - **验收**：AC-02、AC-04。

### 主题身份、命名与阅读导航（PUB）

读者阅读标题和可读路径，系统使用稳定主题身份更新同一主题。首页和分类索引只提供导航，不复制主题正文或审计内容。

- **FR-PUB-003**：每个托管主题页必须持有可机械读取的身份页头和可读标题。
  - **页头合同**：主题页固定使用 `managed_by: KnowledgeDigest`、`digest_kind: topic`、`digest_topic_id`、`digest_published_path` 和 `digest_part`；`digest_published_path` 必须等于该页在知识库内的实际相对路径。
  - **范围边界**：首次标题顺序固定为已有托管标题、来源 title 或 H1、文件名；同名冲突保留可读名称并追加短稳定主题身份；更新可改显示标题但不改 `digest_published_path`。
  - **依据**：D-02、D-04、PFACT-IDENTITY。
  - **场景**：SCN-004。
  - **验收**：AC-03。

- **FR-PUB-004**：系统必须生成或更新托管首页和分类索引，并只链接当前托管主题页。
  - **范围边界**：首页和分类索引不得复制主题正文、Claim、Evidence 或 Provenance；审计目录继续承载来源索引、运行记录和归档，不作为读者入口。
  - **依据**：D-02、D-06、PFACT-SCOPE、PFACT-QUALITY、PFACT-CATEGORY。
  - **场景**：SCN-001、SCN-002、SCN-007。
  - **验收**：AC-01、AC-02、AC-04、AC-07。

### 无删除更新与离线安全（PUB）

每日同步只能添加或更新托管内容。内容重组可以改变当前导航，但不能删除旧路径或降低内容质量门。

- **FR-PUB-005**：系统不得在本任务的任何发布路径删除或改写不再现行的旧分页。
  - **范围边界**：分页收缩时，现行导航只列当前分页；旧分页保留原字节且不在读者导航出现。覆盖当前分页时既有归档合同继续适用。
  - **依据**：D-03、PFACT-PUBLISH、PFACT-QUALITY。
  - **场景**：SCN-005。
  - **验收**：AC-05、AC-07。

- **FR-PUB-006**：离线发布必须在不调用 LLM、embedding 或外部网络的条件下完成或明确失败。
  - **范围边界**：标题、路径和导航只能使用本地已声明资料；本期不提供模型生成标题或文件名。
  - **依据**：D-05、PFACT-OFFLINE。
  - **场景**：SCN-006。
  - **验收**：AC-06。

- **FR-PUB-007**：系统必须区分新空库初始化和已有旧库的空输入。
  - **范围边界**：新空库可生成无主题的读者结构；已有旧库的空输入不得触发重新编目、导航刷新或任何正式文件变化。
  - **依据**：D-01、D-03、PFACT-EMPTY。
  - **场景**：SCN-001、SCN-008。
  - **验收**：AC-01、AC-08。


## 6. 模块划分

### 发布结构合同

- **负责什么**：声明首页、分类索引、可写主题目录、默认待归类目录和托管文件要求。
- **对外提供什么**：可验证的发布范围和读者路径。
- **依赖谁**：知识库维护者提供的结构，或新空库的默认初始化。
- **测试边界**：有效、缺失、冲突和声明外路径的发布结果。

### 主题页发布

- **负责什么**：把完整主题内容发布为带稳定身份和可读展示信息的正式页。
- **对外提供什么**：可从导航访问、可安全更新的主题页。
- **依赖谁**：已验证的主题内容和发布结构合同。
- **测试边界**：首次命名、重复运行、标题变化、分页和同名冲突。

### 读者导航

- **负责什么**：生成首页和分类索引到当前主题页的链接。
- **对外提供什么**：不依赖审计目录的阅读入口。
- **依赖谁**：当前托管主题页及其发布分类。
- **测试边界**：链接完整性、无正文复制和导航更新。

### 托管写入保护

- **负责什么**：在写入前验证目录、托管身份、路径安全和无删除约束。
- **对外提供什么**：对不安全目标明确失败且正式内容不变。
- **依赖谁**：发布结构和拟发布页面。
- **测试边界**：手写页、未声明路径、缺标记、冲突及原子失败。

## 7. 关键实体

- **发布结构**：`kb.structure.md` 对读者入口和系统托管范围的唯一声明。
  - **字段和约束**：保留 Why 与版本字段声明，并新增 `publication_home`、`publication_index_root` 和 `publication_categories`。每个分类有唯一 `id`、非空 `title` 与 `topic_dir`；必须有唯一 `id: pending` 的“待归类”分类；所有路径必须在知识库内且互不冲突。
  - **关系**：决定首页、分类索引和主题页可写位置。

- **托管主题页**：系统可新增或更新的正式知识页。
  - **字段和约束**：页头固定有 `managed_by: KnowledgeDigest`、`digest_kind: topic`、`digest_topic_id`、`digest_published_path`、`digest_part`；正文有可读 H1、Summary、Evidence、Provenance。
  - **关系**：属于一个发布分类，可被首页和分类索引链接。

- **读者导航页**：首页或分类索引。
  - **字段和约束**：页头固定有 `managed_by: KnowledgeDigest` 和 `digest_kind: home` 或 `digest_kind: category`；必须位于声明路径，只放简短说明和链接，不含主题正文或审计正文。
  - **关系**：只链接当前托管主题页和分类索引。

## 8. 数据和生命周期

- **数据粒度**：一条托管主题及其确定性分页、读者导航和来源索引。
- **数据时效**：每次手动运行发布或更新当前主题、首页和分类索引。
- **缺失或迟到**：旧库缺有效发布结构、固定页头、托管标记或安全路径时停止正式写入并说明原因；无法分类进入待归类。
- **预览与正式**：本期只定义正式发布，不新增预览或 dry-run 合同。
- **当前与历史**：当前导航指向现行分页；当前页覆盖前内容按既有合同归档；不再现行的旧分页保持原字节且不删除。
- **归属与清理**：知识库维护者持有页面和归档；本期不提供自动物理清理或全量对账删除。

## 9. 兼容性预留

- **既有消费方**：既有 Claim、Evidence、Provenance、来源索引、归档、单写者和 300 行上限必须继续成立。
- **命名预留**：稳定主题身份保持更新键；显示标题和锁定路径为后续 LLM 命名保留独立位置。
- **容器预留**：发布结构可声明多个分类；本期默认待归类，不承诺自动语义分类。
- **状态预留**：托管主题页、首页和分类索引可被明确区分，避免以后按路径猜测。
- **扩展边界**：Task 2 可提议 LLM 标题、文件名或分类；必须另行定义成本、失败和质量合同。

## 10. 明确不做与默认必须成立

### 明确不做

- 不删除任何旧知识库文件，不做全量对账删除。
- 不用 LLM、embedding 或外部网络生成标题、文件名或分类。
- 不自动接管、改名或迁移既有未托管的哈希主题页。
- 不引入数据库、调度器、CAS、journal、AgentMemory 或向量库。
- 不复制第二份读者正文，也不把审计目录作为读者入口。

### 默认必须成立

- 新空库可直接初始化；非空旧库未声明发布结构时必须失败。
- 只管理声明目录内带系统托管标记的文件。
- 每个现行主题页保留 Summary、Evidence、Provenance、来源可追溯性和 300 行上限。
- 覆盖前归档和原子写继续适用于当前主题页和导航页。
- 新增或更新失败时不得留下部分正式发布结果。
- 已有旧库的空输入不得改变主题页、首页或分类索引。

## 11. 验收标准

- [ ] **AC-01**：新空知识库可直接发布为读者可浏览的结构。
  - **需求**：FR-PUB-001、FR-PUB-004、FR-PUB-007
  - **验证方法**：离线端到端测试新空目标库并检查首页、分类索引、主题页和链接。
  - **通过条件**：`kb.structure.md` 含唯一的首页、索引根和 pending 分类声明；首页可达每个当前主题页；读者链接不进入审计目录；无法分类主题位于待归类分类。
  - **失败条件**：缺首页、死链、仅有审计索引，主题被写到未声明位置，或声明缺少 pending 分类。
  - **证据类型**：`test`

- [ ] **AC-02**：旧库更新仅影响声明范围内的托管文件。
  - **需求**：FR-PUB-002、FR-PUB-004
  - **验证方法**：在含托管页、手写页和声明外文件的旧库上运行离线发布。
  - **通过条件**：系统只新增或更新允许文件；既有主题页含 `managed_by: KnowledgeDigest`、`digest_kind: topic`、`digest_topic_id` 和 `digest_published_path`；导航页只需对应的导航页头；手写页和声明外文件字节不变。
  - **失败条件**：任何手写页、未托管页或声明外文件被创建、覆盖或修改。
  - **证据类型**：`test`

- [ ] **AC-03**：托管主题页具有稳定身份和可读命名。
  - **需求**：FR-PUB-003
  - **验证方法**：覆盖已有标题、H1、文件名、同名冲突和二次更新的离线测试。
  - **通过条件**：页头含 `managed_by: KnowledgeDigest`、`digest_kind: topic`、`digest_topic_id`、`digest_published_path` 和 `digest_part`；标题和文件名可读；二次更新不改锁定路径。
  - **失败条件**：路径随标题变化、主题页只以哈希显示、页头字段缺失，或同名主题发生覆盖。
  - **证据类型**：`test`

- [ ] **AC-04**：结构或托管身份不满足时，发布在写入前明确失败。
  - **需求**：FR-PUB-002、FR-PUB-004
  - **验证方法**：分别构造缺发布结构、未托管旧页、路径冲突和不安全路径。
  - **通过条件**：错误说明具体缺口，且所有正式页面和导航文件保持运行前字节。
  - **失败条件**：系统猜测目录、接受不匹配的 `digest_published_path`、接管未托管页，或失败后留下部分正式结果。
  - **证据类型**：`test`

- [ ] **AC-05**：分页收缩不删除或改写旧分页。
  - **需求**：FR-PUB-005
  - **验证方法**：先发布多分页主题，再用较短内容更新同一主题。
  - **通过条件**：旧分页路径存在且字节不变；首页和分类索引不再链接旧分页；所有现行 Claim 仅属于一个当前分页。
  - **失败条件**：旧分页被删除或改写、旧分页仍在当前导航、Claim 丢失或当前分页重复 Claim。
  - **证据类型**：`test`

- [ ] **AC-08**：已有旧知识库的空输入不改变发布结果。
  - **需求**：FR-PUB-007
  - **验证方法**：对已有托管主题页、首页和分类索引的旧库执行空输入离线运行。
  - **通过条件**：所有正式文件在运行前后字节相同，导航继续指向原当前主题。
  - **失败条件**：任何正式文件被创建、更新、删除，或现有主题从导航消失。
  - **证据类型**：`test`

- [ ] **AC-06**：离线模式不调用外部智能服务。
  - **需求**：FR-PUB-006
  - **验证方法**：在禁用 LLM 和 embedding 的测试环境运行新库与旧库发布。
  - **通过条件**：无 LLM、embedding 或网络请求，且发布合同仍成立。
  - **失败条件**：任何外部请求发生，或系统因缺模型而回退到不可读哈希输出。
  - **证据类型**：`test`

- [ ] **AC-07**：可读发布不降低既有主题质量合同。
  - **需求**：FR-PUB-004、FR-PUB-005
  - **验证方法**：对新旧库发布结果执行内容、分页、溯源、归档和原子失败回归。
  - **通过条件**：每个现行主题页保留 Summary、Evidence、Provenance 和来源可追溯性，且不超过 300 行；失败时无部分正式页。
  - **失败条件**：导航生成造成正文重复、缺少质量段落、超行、失去来源，或写入半完成。
  - **证据类型**：`test`

## 12. 风险、未决与交接

- **RISK-PATH**：离线标题质量受来源标题和文件名质量限制。
  - **受影响 ID**：PFACT-IDENTITY、PFACT-OFFLINE、FR-PUB-003、AC-03、AC-06
  - **触发条件**：来源缺少有意义的 title、H1 或文件名。
  - **后果**：标题可读性有限，但路径仍稳定。
  - **缓解或 STOP**：使用固定回退顺序并标入待归类；不调用模型伪造标题。
  - **处理 Stage**：`build-code`
  - **验证**：标题回退和路径锁定测试。

- **RISK-LEGACY**：既有哈希主题页未声明托管身份。
  - **受影响 ID**：PFACT-SCOPE、FR-PUB-002、AC-02、AC-04
  - **触发条件**：维护者把旧产物作为旧库直接运行。
  - **后果**：系统按保护规则停止，不能自动转换旧页。
  - **缓解或 STOP**：明确失败并要求新建发布库或人工显式托管迁移；自动迁移不属于本期。
  - **处理 Stage**：`verify-code`
  - **验证**：未托管旧库失败且字节不变的测试。

- **RISK-RETENTION**：无删除策略会保留历史分页和归档。
  - **受影响 ID**：PFACT-PUBLISH、PFACT-QUALITY、FR-PUB-005、AC-05、AC-07
  - **触发条件**：主题经常收缩或重组。
  - **后果**：知识库文件数量增长。
  - **缓解或 STOP**：当前导航只列现行分页；保留清理策略给独立生命周期任务。
  - **处理 Stage**：`build-plan`
  - **验证**：分页收缩测试证明导航简洁且旧分页字节不变。

- 后续模型命名和语义分类属于明确排除的 Task 2，不构成本期未决项。

## 13. 业务影响与回归范围

### 新知识库发布

- **既有行为**：维护者需要理解审计目录和哈希主题页才能阅读结果。
- **本需求影响**：从根首页按分类进入可读主题页。
- **回归路径**：首次离线发布、空输入发布、待归类发布、链接完整性。
- **验收**：AC-01、AC-03、AC-04、AC-06、AC-07。

### 旧知识库每日更新

- **既有行为**：系统缺少托管权限判断，旧库写入风险不清楚。
- **本需求影响**：只更新明确托管范围，其他内容受保护。
- **回归路径**：托管主题更新、手写页保护、缺声明失败、分页收缩、旧库空输入。
- **验收**：AC-02、AC-04、AC-05、AC-07、AC-08。

- **可能受冲击的业务规则**：Claim 不丢失、来源可追溯、写前归档、原子写、300 行上限、单写者和离线零模型调用。
- **明确无影响**：LLM 草稿、embedding 选择、批次恢复、AgentMemory、真实语料默认命名和既有未托管页的自动迁移。
