# Data Contracts

| Contract | Owner side | Consumer side | Required fields/types | Validation rules | Version/compatibility notes |
|---|---|---|---|---|---|
| CLI invocation | user / CLI parser | digest pipeline | `new_dir: path`, `kb_dir: path`; optional `config: path`, `dry_run: boolean`, `top_k: integer`, `cluster_auto_threshold: float`, `cluster_review_threshold: float`, `max_doc_lines: integer` | required paths must exist; thresholds must be numeric and ordered so review threshold is below auto threshold; `top_k > 0`; `max_doc_lines > 0` | Phase 0 only supports manual single-run invocation. |
| `new_dir` layout | user / fixture builder | S1 ingest | `items/`; optional `sources.jsonl`; system-created `_digest/work/` | item extensions limited to `.md`, `.txt`, `.json`; unreadable files recorded in ingest failure | Directory-only contract; no database dependency. |
| `sources.jsonl` row | source manifest author | S1 ingest / S6 provenance | `id: string`, `source_uri: string`, `fetched_at: string`, `source_status: string`, `content_path: string` | row must be valid JSON; `content_path` must point under `new_dir/items`; empty-shell or failed sources cannot enter final provenance | Optional; missing rows fall back to file-derived metadata. |
| `kb.structure.md` | KB owner | S3/S5/S6 | `kb_name`, `page_root`, `archive_root`, `queue_root`, `frontmatter_required`, `body_sections`, `provenance_field`, `why_field`, `version_field`, `link_policy`, `optional_index_sync` | required keys must be parseable from the Markdown structure block; defaults apply only where spec defines defaults | Keeps adaptation in a human-readable file, not a code adapter layer. |
| RawItem JSONL | S1 | S2/S4/S6 | `raw_id`, `content_hash`, `text`, `source_uri`, `source_meta`, `fetched_at`, `non_text_refs`, `source_status` | `content_hash` exact dedupe; empty-shell content goes to ingest failure, not RawItem | Stable within one run. |
| Cluster JSONL | S2 | S3/S4 | `cluster_id`, `tier`, `members`, `min_pair_similarity`, `decision_reason`, `source_uris` | complete-linkage rule: a member joins only if it meets threshold against every cluster member; low-signal entries go to queues | Tiers: `auto`, `needs_review`, `insufficient_signal`. |
| EvolutionDecision JSONL | S3 | S4 | `cluster_id`, `action`, `target_paths`, `candidate_paths`, `candidate_scores`, `reason` | action must be `new`, `revise`, or `merge_multiple`; preserve up to `top_k` candidates | Supports multi-page impact without graph DB. |
| Draft JSONL | S4 | S5/S6 | `draft_id`, `cluster_id`, `action`, `target_paths`, `final_body`, `claims`, `removed_claims`, `provenance`, `faithfulness_status`, `split_suggestion` | unsupported claims excluded from `final_body`; faithfulness failure falls back to claim-by-claim output or exits with code 3 | Draft is the last pre-write safety boundary. |
| Queue Markdown | S2/S3/S4/S6 | user | `_queues/needs_review.md`, `_queues/insufficient_signal.md` entries with cluster/source/reason | queue writes must not be treated as product review workflow; dry-run records planned queue changes only in run report | Manual visibility only in Phase 0. |
| Write report JSONL | S5 | run report / user | target path, action, status, archive path, error if any | write via temp file, fsync, atomic rename; failure exits code 4 and preserves official page state | No CAS/journal/two-phase commit in Phase 0. |
| Provenance audit JSONL | S6 | acceptance check | claim id/body, supporting `source_uri`, source status, target path | each final claim has at least one valid source; empty-shell sources count must be zero | Lightweight provenance, not full source-attribution product. |
